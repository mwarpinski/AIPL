# Counting primes

Each line of the input is an integer n, 0 <= n <= 2000000; there are at
most 10 lines. For each, print the number of primes less than or equal to
n, a space, and the largest such prime (0 if there is none).

Example input:

    10
    1
    2

Example output:

    4 7
    0 0
    1 2

Read all of standard input and write the answer to standard output. The
output must match exactly: every line ends with a newline, with no other
trailing spaces or blank lines.
