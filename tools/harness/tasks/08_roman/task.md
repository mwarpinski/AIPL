# Roman numerals

Each line of the input is either an integer from 1 to 3999 or a Roman
numeral for one. Print the other form on its own line. Roman numerals use
`I V X L C D M`, written in the usual shortest way (`IV` for 4, `XC` for
90, `MCMXCIV` for 1994); every numeral in the input is written that way.

Example input:

    1994
    MMXXVI
    4

Example output:

    MCMXCIV
    2026
    IV

Read all of standard input and write the answer to standard output. The
output must match exactly: every line ends with a newline, with no other
trailing spaces or blank lines.
