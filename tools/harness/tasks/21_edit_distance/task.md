# Edit distance

Each line of the input is two words of lowercase letters, separated by a
space; each word has at most 300 letters (a word may be empty, so a line
may start or end with the space). Print, for each line, the edit distance
between them: the fewest single-letter insertions, deletions, and
substitutions that turn the first into the second.

Example input:

    kitten sitting
    flaw lawn
    abc abc

Example output:

    3
    2
    0

Read all of standard input and write the answer to standard output. The
output must match exactly: every line ends with a newline, with no other
trailing spaces or blank lines.
